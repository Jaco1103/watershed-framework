What it is

A memory — and a
way to think.

Watershed is one markdown file you drop into your project. It does two things.

▤

It gives the AI memory

Every decision is written to one living file the AI reads before every session — so the project’s context never lives only in your head.

◷

It makes the AI think first

It challenges assumptions in the right order instead of agreeing with whatever sounds good — like a sparring partner, not a yes-man.

How it works
